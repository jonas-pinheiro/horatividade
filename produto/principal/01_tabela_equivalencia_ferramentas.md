# Tabela de equivalência entre ferramentas

O método usa um conceito só: **repositório** — contexto que fica salvo e vale para todas as conversas, em vez de contexto que você redigita toda vez. Cada ferramenta dá um nome diferente para a mesma coisa.

| Conceito do curso | Claude | ChatGPT | Gemini | Copilot |
|---|---|---|---|---|
| Repositório | Projeto | Projeto (ou GPT personalizado) | Gem | Agente / bloco de anotações |
| Arquivos do repositório | Base de conhecimento do projeto | Arquivos do projeto/GPT | Arquivos do Gem | Arquivos anexados |
| Bloco de diretriz | Instruções do projeto | Instruções (ou "Instruções personalizadas") | Instruções do Gem | Instruções do agente |
| Conversa que enxerga tudo | Conversa dentro do projeto | Conversa dentro do projeto | Conversa com o Gem | Conversa com o agente |
| Geração de .docx/.xlsx | Criação de arquivos | Geração de arquivos (Python) | Exportar para Docs/Planilhas | Exportar para Word/Excel |

## Os nomes de botão mudam. A função não.

As plataformas renomeiam recursos com frequência. Se o menu da sua ferramenta não bater com esta tabela, procure pela **função**: "onde eu anexo arquivos que ficam salvos?" e "onde eu escrevo instruções que valem para todas as conversas?". Achou os dois, achou o repositório.

## Se a sua ferramenta não tem projeto

Dá para aplicar o método mesmo assim, com duas adaptações:

1. Mantenha os arquivos do repositório numa pasta sua (computador ou nuvem) com os nomes padrão (`00_DIRETRIZ`, `01_CALENDARIO`, `02_EMENTA`, `03_TURMAS`, `04_TEMPLATE`).
2. No começo de cada sessão de trabalho, anexe os arquivos e cole a diretriz como primeira mensagem. É menos cômodo, mas o resultado é o mesmo: a IA trabalha com o seu contexto, não com o genérico.

## Se o seu plano não gera .docx/.xlsx

Peça a saída em **tabela markdown** e cole no Word ou no Docs — a estrutura de tabela se mantém. O material da Aula 4 traz o passo a passo.
