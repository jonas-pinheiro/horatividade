# Tabela de equivalência entre ferramentas

O método funciona só com uma pasta no computador e conversas novas — não depende de nenhum recurso específico. Se a sua ferramenta tiver "Projetos" (Claude), Projetos/GPTs (ChatGPT), Gems (Gemini) ou agentes (Copilot), é conveniente, mas opcional: é a mesma pasta, só que guardada dentro da ferramenta.

| O que você precisa | Claude | ChatGPT | Gemini | Copilot |
|---|---|---|---|---|
| Guardar os arquivos (opcional) | Projeto | Projeto ou GPT personalizado | Gem | Agente / bloco de anotações |
| Onde vão os `.md` | Base de conhecimento do projeto | Arquivos do projeto/GPT | Arquivos do Gem | Arquivos anexados |
| Onde vai a diretriz (`00_DIRETRIZ`) | Instruções do projeto | Instruções | Instruções do Gem | Instruções do agente |
| Gerar `.docx`/`.xlsx` | Criação de arquivos | Geração de arquivos | Exportar para Docs/Planilhas | Exportar para Word/Excel |

## Os nomes de botão mudam. A função não.

As plataformas renomeiam recursos com frequência. Se o menu da sua ferramenta não bater com esta tabela, procure pela **função**: "onde eu guardo arquivos que ficam salvos?" e "onde eu escrevo instruções que valem para todas as conversas?". Achou os dois, achou o repositório.

## Se a sua ferramenta não tem Projetos (ou você prefere não usar)

Funciona igual. Mantenha os arquivos numa pasta sua (computador ou nuvem), com os nomes padrão (`00_DIRETRIZ`, `01_CALENDARIO`, `02_EMENTA`, `03_TURMAS`, `04_TEMPLATE`), e a cada conversa nova anexe os que aquela tarefa precisa, com a diretriz colada como primeira mensagem se a ferramenta não tiver campo de instruções. É menos cômodo, mas o resultado é o mesmo: a IA trabalha com o seu contexto, não com o genérico.

## Se o seu plano não gera .docx/.xlsx

Peça a saída em **tabela markdown** e cole no Word ou no Docs — a estrutura de tabela se mantém. O material da Aula 4 traz o passo a passo.
