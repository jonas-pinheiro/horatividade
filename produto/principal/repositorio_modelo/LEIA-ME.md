# LEIA-ME — como usar este repositório-modelo

Esta pasta é o esqueleto do seu repositório. Cada arquivo diz, dentro dele, o que é e como preencher. Preencheu os cinco primeiros, seu projeto está alimentado.

## A arquitetura: um projeto por DISCIPLINA, não por turma

Crie **um projeto na sua ferramenta de IA para cada disciplina** que você leciona, e suba nele estes arquivos preenchidos. As turmas moram *dentro* do arquivo `03_TURMAS.md` e aparecem como coluna no template — não como projetos separados.

Por quê: o plano gratuito do Claude permite cinco projetos. Professor com três disciplinas e cinco turmas estouraria a cota no primeiro dia se criasse um projeto por turma — e perderia o repositório em outubro. Um por disciplina escala: o conteúdo é o mesmo, muda o ritmo por turma, e isso o perfil de turmas resolve.

## Ordem de preenchimento

| Arquivo | O que é | Material de apoio que ajuda |
|---|---|---|
| `00_DIRETRIZ.md` | as instruções do projeto | Bloco de diretriz comentado (Aula 3) |
| `01_CALENDARIO.md` | as datas reais do seu ano | — |
| `02_EMENTA.md` | o esqueleto do seu conteúdo | Checklist de pré-requisitos (Aula 0) |
| `03_TURMAS.md` | suas turmas, em agregado | Roteiro da entrevista reversa (Aula 2) |
| `04_TEMPLATE.md` | o formato que a coordenação aceita | Prompt do template reverso (Aula 4) |
| `05_ATA_DO_PROJETO.md` | o diário de correções | Aula 8 |

O conteúdo de `00_DIRETRIZ.md` vai no campo **instruções do projeto**; os demais entram como arquivos na base de conhecimento. Os nomes numerados deixam você dizer "use o 01" e mantêm o repositório legível no ano que vem.

## Regra inegociável

Nenhum dado de aluno identificável em nenhum arquivo. Nome, nota, laudo, contato: não entram. Perfil de turma é do grupo, não de pessoas.
